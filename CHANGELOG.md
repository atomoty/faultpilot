# Changelog

All notable changes to FaultPilot will be documented in this file.

## [Unreleased]

### Added

- Runnable `v0.1.0` Mock-mode troubleshooting flow with deterministic rules and fallback reports.
- REST endpoints for diagnoses, report lookup, project listing, health checks, and local-demo event ingestion.
- Built-in browser test console for one-click Mock diagnosis verification.
- Maven multi-module build and CI verification.

### Security

- Best-effort evidence redaction before storage and report generation.
- Secure-by-default event ingestion with Bearer-token project/environment binding.

## [0.0.1] - 2026-06-01

### Added

- Initial documentation release.
- Product scope, MVP requirements, technical design, ADRs, and development plan.
- Chinese documentation with an English project overview.
- GitHub community files, issue templates, and documentation checks.
